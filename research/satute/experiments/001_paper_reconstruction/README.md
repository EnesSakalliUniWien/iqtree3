# 001 - Paper reconstruction

Reconstructs the original SatuTe simulation design and reduced Fig. 2 evidence.
This is a historical baseline, not the primary weighted-statistic power result.

- Driver: `run.py`
- Renderer: `render.py`
- Manifest and run configuration: `experiment.json`
- Common workflow adapter: `workflow.py`
- Reviewed legacy summaries: `../../artifacts/releases/legacy/`

The archived manuscript supplies the final main and misspecification PDFs but
not their historical raw simulation tables. The canonical publication-figure
builder indexes those exact PDFs under
`../../artifacts/publication/power/original-paper/` and links the current full
JC and misspecification reconstruction tables beside them. The provenance note
there distinguishes reconstruction data from unavailable historical inputs.
